\# Live Polling App



A real-time live polling application built with React and Go.



\## Tech Stack



\### Frontend

\- React

\- Vite

\- JavaScript



\### Backend

\- Go

\- Gin



\## Project Structure



\- `frontend/` – React frontend

\- `backend/` – Go + Gin backend
